# Equinox support / Поддержка Equinox

## English

Equinox is a free menu bar calendar for Apple Silicon Macs running macOS 26 or later.

- **Contact:** [Open an issue](https://github.com/ksandrpetrov/equinox/issues/new) for the project maintainer. Include the Equinox version (Settings → About), macOS version and steps to reproduce. GitHub requires an account to submit an issue.
- **Privacy:** Issues are public. Use fictional events and redact personal details, meeting URLs and access codes from screenshots. [Privacy policy](PRIVACY.md).
- **Find the app:** Click Equinox in the macOS menu bar. Use its panel menu to open Settings or quit. It normally has no Dock icon.
- **Missing events:** Enable Full Access for Equinox in System Settings → Privacy & Security → Calendars, then check Settings → Calendars in Equinox. Calendars must already be configured in macOS; Equinox does not sign in to calendar providers.
- **Create or delete:** Select a writable calendar to create an event. Read-only calendar events cannot be deleted. Existing events cannot be edited in Equinox; use your calendar app.
- **Meetings:** Click a meeting link to open the installed meeting client or browser. A meeting service may require its own account.
- **Startup:** Enable launch at login in Settings → General. macOS may ask you to approve it in Login Items.
- **Updates:** For the Mac App Store edition, use App Store updates.

## Русский

Equinox — бесплатный календарь для строки меню Mac на Apple Silicon с macOS 26 и новее.

- **Связь с автором:** [Создать обращение](https://github.com/ksandrpetrov/equinox/issues/new). Укажите версию Equinox из раздела «О Equinox», версию macOS и шаги воспроизведения. Для отправки нужен аккаунт GitHub.
- **Конфиденциальность:** Обращения публичны. Используйте вымышленные события; удалите личные данные, ссылки и коды встреч со скриншотов. [Политика конфиденциальности](PRIVACY.md).
- **Где приложение:** Нажмите значок Equinox в строке меню macOS. Настройки и выход доступны через меню панели. Обычно значка в Dock нет.
- **Нет событий:** Включите полный доступ для Equinox в системных настройках конфиденциальности, затем проверьте выбранные календари в настройках приложения. Аккаунты календарей должны быть настроены в macOS.
- **Создание и удаление:** Нужен календарь с доступом на запись. События read-only календарей удалить нельзя. Редактирование существующих событий в Equinox не поддерживается.
- **Встречи:** Ссылка открывает установленный клиент или браузер. Сервис встречи может требовать свой аккаунт.
- **Автозапуск:** Включается в разделе «Основные»; может понадобиться подтверждение в объектах входа macOS.
- **Обновления:** Версия из Mac App Store обновляется через App Store.
