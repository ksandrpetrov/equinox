# Equinox: глубокая проверка 25–26 сентября 2026

Статус: проверка и выпуск продолжаются. Загрузка архива и доступность внешней беты подтверждаются отдельно.

## Среда и границы

- Apple Silicon, macOS 27.0 (26A428), Xcode 27.0 (27A266a).
- Минимальная версия приложения — macOS 26. Живого прогона на macOS 26 нет; по решению пользователя это не блокирует бету.
- Живые операции выполняются в календаре «Из почты», по уточнению пользователя. Удаляются только созданные в этой проверке события с префиксом `Equinox QA`.
- Приложение запускается локально только в Release. Тестовые сервисы используются в XCTest, без чтения/изменения личного календаря тестовым процессом.
- Скриншоты, логи и xcresult находятся в игнорируемом каталоге `build/DeepQA/2026-09-25` и `build/Tests/results`. Скриншоты с личными данными не публикуются в GitHub.

По отдельному запросу пользователя создание и просмотр события перенесены в выдвижную панель слева. Высота календаря сохраняется, содержимое формы прокручивается, закрытие — стрелкой или Escape. Кнопка «Готово» убрана, «Добавить» сохраняет событие. Выбор даты использует сетку и компоненты Equinox, с клавиатурной навигацией и вводом года. Подтверждение удаления остаётся отдельным диалогом. Основной календарь временно недоступен при открытой форме; сохранение и удаление защищены от повторных действий.

Ручка сворачивания расположена по центру разделителя: видимая ширина 12 точек, высота 120 в M, область нажатия остаётся 30. Escape сначала закрывает календарь выбора даты, затем форму; введённый текст при первом Escape сохраняется.

## Выполненные прогоны

- Исходная точка: 364 обычных + 8 графических тестов в Debug и Release, 744 выполнения, без ошибок и пропусков (`run-iQrk4V`).
- Исходная точка: Address Sanitizer и Thread Sanitizer — по 364 теста, без ошибок; статический анализ Release завершился успешно.
- Финальное состояние кода сборки 5: 369 обычных + 12 графических тестов в Debug и Release, **762 выполнения, без ошибок и пропусков** (`run-iJUh6n`). Предыдущий полный прогон также прошёл (`run-iY3jxV`).
- Графические проверки на русском: 12 без ошибок и пропусков (`graphics-ru-final.xcresult`). Проверяются S/M/L, glass/solid, светлое/тёмное оформление, длинные строки и состояния доступа, загрузки, пустых данных и ошибок.
- Address Sanitizer и Thread Sanitizer после основных исправлений: по 369 обычных тестов, без ошибок, пропусков и runtime warnings (`asan-after.xcresult`, `tsan-after.xcresult`). Окончательный интерфейс дополнительно прошёл по 12 графических тестов с каждым sanitizer, также без ошибок, пропусков и runtime warnings (`graphics-asan-final.xcresult`, `graphics-tsan-final.xcresult`). ASan-прогон выполнен на английском.
- Заключительный статический анализ Release успешен (`analyze-final.log`). Предупреждений компилятора в собственном коде нет. Xcode сообщает об отсутствии необязательной зависимости AppIntents при извлечении метаданных; macOS 27 также пишет системные диагностические сообщения linkd/Spotlight, присутствующие у изолированного тестового host.
- Геометрия выдвижной панели: проверены ширина, неизменная высота, правый и верхний края в S/M/L (`run-Hxq5uD`). У края экрана положение ограничивается видимой областью.
- Живые проверки: шесть вкладок настроек; создание timed-события с местом и URL; валидация пустого названия и некорректного URL; два daily all-day повторения; распознавание Google Meet и открытие Chrome с ошибкой тестовой ссылки; горячие клавиши формы; сохранение выбора календаря после перезапуска.
- Нагрузочная проверка: 24 быстрых перехода с 4155 синтетическими событиями, Release — 0,418 с суммарно, худший переход 0,048 с; не более двух обращений к подставному хранилищу. Это измерение тестового сценария, а не сетевой синхронизации EventKit.
- Отдельные проверки ошибок, задержек, гонок загрузки, восстановления разрешений, дат, повторов и напоминаний выполняются с CalendarEventStore и несохранёнными объектами EventKit в XCTest.

## Ограничения живой автоматизации

- Средство управления не подключается к Equinox без видимого окна; панель несколько раз открывал пользователь.
- Приложение macOS «Календарь» не подключается к средству управления. По указанию пользователя используется существующий календарь «Из почты».
- Браузерная политика заблокировала открытие `equinox://…`; обход не выполнялся. Обработка допустимых/ошибочных ссылок проверяется XCTest.
- После локальной пересборки macOS перестала принимать прежнюю временную подпись: журнал TCC подтвердил несовпадение code requirement. Следующая локальная Release-сборка подписана существующим Developer ID через игнорируемый Local.xcconfig. Системное разрешение ожидает ручного ответа: средство управления не имеет права работать с UserNotificationCenter.

## Наблюдение при очистке событий

После удаления первого из двух all-day повторений соседнее осталось. После удаления второго первое однократно появилось вновь. Повторное удаление очистило обе даты, затем удалено timed-событие. Причина повторного появления пока не установлена; проверка после перезапуска и повторное воспроизведение ожидают восстановления доступа macOS. Не добавлялось скрытие событий или обход синхронизации без доказанной причины.
