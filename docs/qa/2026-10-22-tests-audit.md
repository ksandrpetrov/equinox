# Аудит автотестов — 22–23 октября 2026

Аудит обоих XCTest targets завершён. Итоговый набор: **394 unit + 37 graphics**
(исходная точка этого прохода: 399 + 29). Финальная серия дала
**21 550 успешных выполнений**, без failures/skips, expected failures,
runtime warnings в xcresult и диагностик, отвергаемых раннером. Unit-набор также
прошёл Thread Sanitizer в Debug и Release: ещё **788 выполнений**.
Это наблюдение на проверенной машине и версиях macOS/Xcode, а не гарантия отсутствия
будущих флаков или любых регрессий.

## Что изменено

- Объединены повторы native meeting URLs, разрешений календаря, календарных списков,
  навигации, хранения выбора, плотных agenda и распознавания провайдеров. Сохранены
  уникальные входы, проверки DST, поддерживаемых дат и больших наборов событий.
  Из графических проверок убраны повторные рендеры, не зависящие от темы.
- Частичные сравнения URL заменены точными, проверяются порядок и приоритеты событий,
  границы диапазонов, callbacks, отмена запросов, поколения кэша и настройки после
  повторного создания PreferencesStore. Ошибка в большом корпусе теперь даёт короткую
  диагностику первого расхождения вместо тысяч повторных assertions.
- Ожидания асинхронных действий ограничены по времени; удерживаемые continuation
  освобождаются. Таймеры проверяются управляемыми callbacks без ожидания реальной минуты.
  Контекст календаря фиксирован; UserDefaults изолирован. В графических fixtures
  проверяется наблюдаемая готовность, отключены внешние текстовые сервисы тестового
  редактора, идентификация окна не зависит от текущего активного приложения.
- Усилены реальные действия hosted UI: ввод и отправка формы, запрет невалидной
  отправки, клавиши календаря и date picker, Escape и нативные sheets, открытие
  drawers, переключение pin, изменение размеров уже открытой панели, уведомления
  menu bar, поиск настроек и жизненный цикл записи сочетаний клавиш.
- Раннер использует существующие Xcode targets. Добавлены повторения в случайном
  порядке, Thread Sanitizer и изолированный возобновляемый мутационный аудит.
  Пустые/неполные результаты, skips, expected failures, известные runtime diagnostics
  и перезапуски test host не дают ложного успешного результата.

В коде приложения относительно исходного мутационного снимка изменены два файла:
`SettingsActivationHandler` задаёт исходный размер hosted content до присоединения
к окну, устраняя предупреждения конфликтующих constraints; `EquinoxFormatters`
принимает явные locale/timeZone для проверки смены контекста, сохраняя прежние
autoupdating defaults в production. Остальные ранее существовавшие изменения
рабочего дерева этим аудитом не присваиваются. Signing и зависимости GUI не менялись.

со случайным порядком и перезапуском процесса между итерациями. Это повторение всех

## Ограничения

Остаются **259 мутаций, не обнаруженных тестами**: 78 относятся к оформлению,
43 — к содержимому UI, 80 — к действиям UI, 13 — к accessibility-контрактам,
44 — к платформенным интеграциям и одна — к платформенному состоянию.
Это число мутаций, а не независимых багов или сценариев. Среди пробелов — реальный CalendarStore/EventKit/TCC,
Launch at Login, открытие внешних приложений, часть menu bar и settings действий.
Hosted graphics tests не заменяют проверку этих сценариев с системными сервисами.
Наличие чистого рендера не используется как основание объявить такую мутацию
эквивалентной или пойманной.

Ручная проверка GUI после Release-запуска не выполнена: финальное обращение через native UI automation подтвердило, что Mac заблокирован. Проверки живого EventKit/TCC, внешних приложений и системных разрешений также не объявляются пройденными.

Мутационный аудит сохраняет ненулевой exit code при выживших или иных не-assertion
исходах; частичная перепроверка также не выдаётся за успешный полный аудит.
Следовательно, `--mode all` не является зелёным ежедневным gate для текущего
каталога. Для короткого регрессионного прогона используется:

```bash
./scripts/test.sh --mode regression
```

Отдельные длительные проверки:

```bash
./scripts/test.sh --mode stability
./scripts/test.sh --suite unit --thread-sanitizer
./scripts/test.sh --mode mutation
```
