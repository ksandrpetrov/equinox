# equinox

equinox — календарь для строки меню macOS. В нём можно быстро посмотреть месяц и ближайшие события, создать или удалить событие, проверить свой статус участия и открыть ссылку на встречу.

## Что умеет приложение

### Календарь и панель

- **Месячная сетка** — компактный календарь с выбранным днём, сегодняшней датой, границами месяца, номерами недель и отметками событий.
- **Список событий** — события выбранного и ближайших дней. Пустые дни и места проведения можно скрыть.
- **Навигация** — переход по месяцам, возврат к сегодняшнему дню, выбор дня в сетке и ссылка вида `equinox://date/yyyy-MM-dd`.
- **Создание событий** — название, дата и время, событие на весь день, календарь, место, URL, заметки, повтор и напоминание.
- **Просмотр и удаление** — карточка показывает время, календарь, место, заметки, ссылку на встречу и статус участия. Удалить событие можно только из календаря с доступом на запись.
- **Фильтрация календарей** — календари сгруппированы по источникам; календари только для чтения тоже можно показать или скрыть.
- **Обычная или закреплённая панель** — панель открывается из строки меню и при необходимости остаётся на экране в отдельном окне. После перезапуска это состояние восстанавливается.
- **Управление с клавиатуры** — глобальная горячая клавиша, `T` для возврата к сегодняшнему дню, `Cmd+N` для нового события, `P` для закрепления панели и `Cmd+,` для настроек.
- **Подключение к встречам** — приложение ищет ссылки в URL, месте и заметках события. Поддерживаются Zoom, Microsoft Teams, Amazon Chime, Google Meet, Webex, VK Calls, FaceTime, GoToMeeting, RingCentral, BigBlueButton, Jitsi, Senfcall и Workplace. Zoom, Teams и Chime открываются в нативном приложении, если оно установлено.

Редактирование существующего события в GUI намеренно не поддерживается.

### Оформление и строка меню

- **Настраиваемый значок** — в строке меню можно показывать дату, день недели, месяц и часы либо скрыть календарную часть значка. Индикатор подскажет, что встреча скоро начнётся.
- **Темы и размеры** — системная, светлая или тёмная тема; стеклянный или непрозрачный фон; три размера панели.
- **Настройки отображения** — отметки событий, номера недель, места проведения, пустые дни в списке, границы месяца и подсветка выбранных дней недели.
- **Запуск при входе** — приложение может открываться вместе с системой.
- **Конфиденциальность** — отдельная вкладка показывает состояние доступа к календарям macOS.
- **Локализация** — базовый язык английский, также есть русский перевод в `ru.lproj`. Процесс обновления перевода описан в [BUILD.md](BUILD.md).

### Настройки

В окне настроек есть разделы «Основные», «Календари», «Оформление», «Конфиденциальность», «Горячие клавиши» и «О Equinox». Здесь настраиваются автозапуск, первый день недели, список событий, закрепление панели, видимые календари и внешний вид.

## Требования

| Компонент | Требование |
|-----------|------------|
| Платформа | Mac на **Apple Silicon** (M1 или новее); Intel не поддерживается |
| macOS | **26.0** или новее |
| Сборка GUI | Xcode |
| Доступ к календарю | EventKit full-access API для `equinox.app` |

## Быстрый старт

```bash
cp Local.xcconfig.example Local.xcconfig
./run.sh
```

`./run.sh` собирает приложение в **Release** и запускает equinox. После старта ищите иконку в строке меню.

`Local.xcconfig` хранит настройки подписи кода вне репозитория и добавлен в `.gitignore` — не коммитьте его. Подробнее — в [BUILD.md](BUILD.md).

## Тесты

Swift unit-тесты (XCTest):

```bash
xcodebuild -project equinox.xcodeproj -scheme equinox -configuration Debug \
  -derivedDataPath build/DerivedData test
```

## Архитектура

equinox — гибрид **AppKit-оболочки и SwiftUI-панелей**. Бизнес-логика дат, сетки, раскладки событий, RSVP-статуса и join URL живёт в `Core/`. Доступ к EventKit идёт только через `CalendarStore`; UI не обращается к `EKEventStore` напрямую.

```
equinox/        — приложение в строке меню (Swift/SwiftUI + AppKit)
  App/            — жизненный цикл, AppState, coordinators, Constants
  Core/           — чистая логика (тестируемая)
  Services/       — EventKit, настройки, платформенные хелперы
  UI/             — SwiftUI-вью и design tokens
equinoxTests/   — XCTest
scripts/        — вспомогательные скрипты сборки и проверки
```

Подробная схема слоёв и потоков данных — в [ARCHITECTURE.md](ARCHITECTURE.md).
